{% comment %} Shared setup for every theme template. The four user-driven slots (primary, secondary, surface, text) are always overridden from the party's palette. The ~15 derived tonal slots (surface-container-low/high, outline, primary-container, etc.) come from the design-system "family" tokens — Ethereal Union for the light themes, Midnight Garden for the dark ones, Wildflower Wreath for the "garden" ones — so a custom palette still feels coherent with the template's intended depth and accents. The "garden" family also swaps the typeface pair: it is a translation of a printed, engraved invitation, so it loads Cinzel (all-caps Roman serif) for every block of copy and Pinyon Script for the calligraphic display lines, instead of the DM Sans / Playfair Display pair every other family uses. `theme.family` is passed in by the view; defaults to "ethereal". {% endcomment %} {{ party.name }} — Invitation {% comment %}Cinzel is requested at 400 and 600 only — those are the two weights the garden templates actually set (body copy and `font-semibold`).
